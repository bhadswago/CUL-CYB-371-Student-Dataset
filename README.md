# CUL-CYB 371 - Assignment Two

## Fictional Student Dataset

This project contains a fictional dataset of 10 students for the Data Mining and Data Warehousing assignment.

### Dataset fields
1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

### Files
- `student_dataset.py`: Python program that creates the dataset.
- `students.csv`: Dataset saved in CSV format.

### How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run: `python student_dataset.py`
4. The program creates `students.csv`.

All student records are fictional and created for academic practice.
